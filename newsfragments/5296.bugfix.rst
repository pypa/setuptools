Fixed a regression where a ``package_data`` file with a ``.py`` extension, living in a directory that also gets picked up as an implicitly discovered package, could end up with its mode reset when built into a wheel. This happened because such a file gets copied twice (once as a module, once as package data), and the two copies could land close enough in time that the second one was skipped as already up to date, leaving the mode from the first copy (which does not preserve it) in place.
