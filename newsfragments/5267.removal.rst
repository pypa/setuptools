Removed the MSVC compiler's ``spawn`` compatibility shim that tolerated third-party monkeypatches whose ``spawn`` did not accept an ``env`` argument (added for numpy.distutils versions predating numpy 1.19, per pypa/distutils#15). A replacement ``Compiler.spawn`` must now accept the ``env`` keyword. The ``Compiler.spawn`` signature is correspondingly narrowed to ``spawn(cmd, *, env=None)``.
